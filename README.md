# 随声输入

一款适用于 Windows 的本地语音输入软件：在其他文本编辑器中放好光标，通过全局快捷键或置顶悬浮球录音，使用本地 Whisper 将语音转换为文字，并在验证原输入位置后写入。

当前版本为 **0.3.1（AI 优化阶段）**。普通语音输入完全在本地运行，默认不保存录音、不开启历史、不上传音频。可选 AI 使用真实 OpenAI 兼容 Chat Completions，默认关闭，密钥由 Windows DPAPI 当前用户加密，结果必须预览确认后才写入。用户已用 0.3.0 在真实 DeepSeek 服务上验证连接、三点优化、预览及不自动写入；当时记事本确认写入出现乱码。0.3.1 已修复该问题，通过自动回归，并由用户明确确认实机验收完成。

## 当前进度

- **第一阶段 0.1.0**：完成麦克风录音、本地 CPU Whisper、自定义全局快捷键、安全 Unicode 写入、悬浮球、托盘、单实例和自启动设置。
- **第二阶段 0.2.1**：增加按住说话、可选静音结束、文字处理与替换、自定义悬浮球图片、深浅主题和默认关闭的历史。用户实机确认 A3 长按和快捷键修改通过；B2 休眠唤醒后仍录音仍未解决，按用户决定暂缓修复。
- **第三阶段 0.3.1**：实现真实 OpenAI 兼容客户端、HTTPS/回环地址限制、DPAPI 密钥、五类内置及自定义模板、优化强度和扩写控制、原文/结果分区、编辑复制、取消、迟到结果隔离及确认后安全写入；主面板、设置、AI 面板、悬浮球和托盘状态同步。0.3.1 将 Unicode 写入改为逐字符提交，修复真实记事本中的中文乱码。
- **下一步**：继续补真人设备、真实聊天软件、游戏普通输入区域、自启动重登和多环境兼容性测试。

完整更新记录、待确认事项及后续计划见 [QODER_CN_HANDOFF.md](QODER_CN_HANDOFF.md)。

## 技术栈

- C#、.NET 10、WPF、win-x64
- NAudio 2.2.1
- Whisper.net 1.8.1，本地 CPU 推理

## 从源码运行

```bash
dotnet run --project src/Suisheng/Suisheng.csproj
```

也可以在 Windows 上双击 `运行当前源码.cmd`。

首次识别前，在“模型与录音”页面准备 Base 或 Tiny GGML 模型。模型文件较大，不提交到 Git；本地发布目录和构建产物也不入库。

## 测试与发布

准备测试所需模型后运行：

```bash
tests/run-tests.cmd
```

构建独立第三阶段发布目录：

```bash
packaging/build.cmd
```

发布脚本输出到 `dist/Suisheng-stage3-0.3.1-win-x64`，包含程序、Base 模型和许可，不覆盖旧阶段目录。该目录是免安装发布，不是正式安装包。

## 安全边界

启动和自启动后不自动录音；取消、切换目标或目标失效后不继续自动写入；不自动发送消息、提交表单或执行命令；不绕过密码框、锁屏、UAC、反作弊或 Windows 权限限制。AI 默认关闭，连接测试和优化前明确提示发送文字及费用风险；密钥不得明文保存、进入日志或提交，优化结果默认预览确认。
