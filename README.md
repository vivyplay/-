# 随声输入

一款适用于 Windows 的本地语音输入软件：在其他文本编辑器中放好光标，通过全局快捷键或置顶悬浮球录音，使用本地 Whisper 将语音转换为文字，并在验证原输入位置后写入。

当前版本为 **0.2.0（第二阶段）**。普通语音输入完全在本地运行，默认不保存录音、不开启历史、不上传音频。外部 AI 提示词优化尚未实现，不使用模拟 API 或虚假按钮代替。

## 当前进度

- **第一阶段 0.1.0**：完成麦克风录音、本地 CPU Whisper、自定义全局快捷键、安全 Unicode 写入、悬浮球、托盘、单实例和自启动设置。
- **第二阶段 0.2.0**：增加按住说话、可选静音结束、文字处理与替换、自定义悬浮球图片、深浅主题、默认关闭的历史记录，并完成本轮专项测试及新 Release 回归。
- **下一步**：先补真人麦克风、物理键盘、锁屏休眠、自启动重登及多屏实机确认，再实现真实外部 AI API、安全凭据、可编辑模板和预览确认写入。

完整更新记录、待确认事项及后续计划见 [QODER_CN_HANDOFF.md](QODER_CN_HANDOFF.md)。

## 技术栈

- C#、.NET 10、WPF、win-x64
- NAudio 2.2.1
- Whisper.net 1.8.1，本地 CPU 推理

## 从源码运行

```bash
dotnet run --project src/Suisheng/Suisheng.csproj
```

也可以在 Windows 上双击 `运行当前源码.cmd`。

首次识别前，在“模型与录音”页面准备 Base 或 Tiny GGML 模型。模型文件较大，不提交到 Git；本地发布目录和构建产物也不入库。

## 测试与发布

准备测试所需模型后运行：

```bash
tests/run-tests.cmd
```

构建独立第二阶段发布目录：

```bash
packaging/build.cmd
```

发布脚本输出到 `dist/Suisheng-stage2-win-x64`，包含程序、Base 模型和许可，不覆盖旧阶段一目录。该目录是免安装发布，不是正式安装包。

## 安全边界

启动和自启动后不自动录音；取消、切换目标或目标失效后不继续自动写入；不自动发送消息、提交表单或执行命令；不绕过密码框、锁屏、UAC 或 Windows 权限限制。后续 AI 功能必须默认关闭，密钥不得明文保存或提交，优化结果默认预览确认。
