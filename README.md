# 随声输入

一款适用于 Windows 的本地语音输入软件：在其他文本编辑器中放好光标，通过全局快捷键或置顶悬浮球录音，使用本地 Whisper 将语音转换为文字，并在验证原输入位置后写入。

当前版本为 **0.4.0（正式分发阶段）**。普通语音输入完全在本地运行，默认不保存录音、不开启历史、不上传音频。可选 AI 使用真实 OpenAI 兼容 Chat Completions，默认关闭，密钥由 Windows DPAPI 当前用户加密，结果必须预览确认后才写入。

## 安装与使用

正式安装包：`dist/Suisheng-Setup-0.4.0-win-x64.exe`

1. 双击安装包，按向导完成安装。默认安装到 `%LOCALAPPDATA%\Programs\Suisheng`，每用户安装，默认不要求管理员权限。
2. 首次运行会显示六页引导，依次说明麦克风、模型、快捷键、悬浮球、安全输入测试和可选 AI 数据发送。引导不会自动录音、下载模型或发送 AI 请求。
3. 将光标放到普通文本输入框，按默认 `Ctrl+Alt+Space` 或单击悬浮球开始录音，再按一次结束。
4. 已有设置、模型、历史、AI 模板和 DPAPI 密钥默认保存在 `%LOCALAPPDATA%\Suisheng`。API Key 只能由用户在本机 AI 配置界面输入。

同时提供免安装自包含目录：`dist/Suisheng-stage4-0.4.0-win-x64`。必须保留完整目录，不能只复制 `Suisheng.exe`。

### 升级

当前没有在线更新服务。退出随声输入后，运行同系列新版安装包覆盖安装即可；不要先删除用户数据目录。0.4.0 已实际验证从 0.3.1 覆盖升级，并保留安装目录中的无关文件和外部用户文件。

### 卸载

可通过 Windows 已安装应用或安装目录中的卸载程序卸载。卸载会删除本软件安装的程序文件，并清理本软件注册的 `Suisheng` 开机启动项。

交互卸载会询问是否删除默认用户数据：

- 选择“否”：保留设置、模型、历史、导入图片、AI 模板和 DPAPI 密钥，供重新安装后使用。
- 选择“是”：删除 `%LOCALAPPDATA%\Suisheng` 中上述数据。
- 两种选择都不会删除用户在其他目录自行放置的模型或文件，也不会清空安装目录中的其他无关文件。

**验证边界：**保留数据分支已实际验证；主动选择“是”删除数据的分支为避免破坏真实用户数据，仅做脚本静态检查，仍标记未验证。

## 首次引导、手动更新和诊断

“阶段与帮助”页可以重新打开首次引导、查看手动更新步骤和导出诊断信息。

诊断只在用户主动点击导出并选择保存位置后生成。白名单内容包括应用和系统版本、麦克风数量、模型文件是否存在、模型位置类别、部分功能开关及启动项状态；不包含音频、正文、历史、剪贴板、完整 API 请求、接口地址、完整目录路径或密钥。

## 技术栈

- C#、.NET 10、WPF、win-x64
- NAudio 2.2.1
- Whisper.net 1.8.1，本地 CPU 推理
- Inno Setup 6，每用户安装包

## 从源码运行

```bash
dotnet run --project src/Suisheng/Suisheng.csproj
```

也可以在 Windows 上双击 `运行当前源码.cmd`。

首次识别前，在“模型与录音”页面准备 Base 或 Tiny GGML 模型。模型文件较大，不提交到 Git；本地发布目录和构建产物也不入库。

## 测试与构建

准备测试所需模型后运行核心及 Debug 桌面测试：

```bash
tests/run-tests.cmd
```

构建独立自包含目录：

```bash
packaging/build.cmd
```

输出到 `dist/Suisheng-stage4-0.4.0-win-x64`，包含程序、Base 模型和 4 份许可文件，不覆盖旧阶段目录。

安装 Inno Setup 6 后构建正式安装包：

```bash
packaging/build-installer.cmd
```

输出到 `dist/Suisheng-Setup-0.4.0-win-x64.exe`。
